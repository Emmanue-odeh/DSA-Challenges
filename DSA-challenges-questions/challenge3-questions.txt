Challenge 1: Two Sum Without Nested Loops
Problem


Write a function:
def two_sum(numbers, target):
    pass
Return the indices of two numbers whose sum equals target.
Example
Input: [2, 7, 11, 15], target = 9
Output: [0, 1]
Constraints
Do not use nested loops.
Aim for O(n) time.
Return None if no pair exists.
Vital Hints
While visiting each number, ask:
What number would I need to reach the target?
Store previously seen numbers and their indices.
A dictionary can give you fast lookups.

Challenge 2: Longest Sequence of Consecutive Numbers
Problem
Write:
def longest_consecutive(numbers):
    pass
Return the length of the longest sequence of consecutive numbers.
Example
Input:
[100, 4, 200, 1, 3, 2]

Output:
4
Because:
1, 2, 3, 4
is the longest consecutive sequence.
Constraints
The numbers do not need to be sorted.
Try to solve it without sorting.
Aim for O(n) time.
Vital Hints
A set can make checking whether a number exists very fast.
Do not start counting from every number.
Ask:
Is this number really the beginning of a sequence?
A number is a possible starting point when the number before it does not exist.



Challenge 3: Valid Parentheses with Multiple Bracket Types
Problem

Write:
def valid_parentheses(text):
    pass
Check whether brackets are correctly matched.
Support:
()
[]
{}
Examples
"{[()]}" → True
"([)]"   → False
"((()))" → True
"{[}"    → False
Constraints
Brackets must close in the correct order.
Return False for mismatched brackets.
Vital Hints
Opening brackets should be remembered.
The most recently opened bracket must close first.
That behaviour is LIFO.
A dictionary can help connect:
")" → "("
"]" → "["
"}" → "{"

Challenge 4: Minimum Number of Coins
Problem

You are given a list of coin values and an amount.
Write:
def minimum_coins(coins, amount):
    pass
Return the minimum number of coins needed to make the amount.
Example
coins = [1, 2, 5]
amount = 11

Output:
3
Because:
5 + 5 + 1
uses three coins.
If the amount cannot be formed, return -1.
Vital Hints
A greedy solution will not always work.
Think about solving smaller amounts first.
For every amount, ask:
What smaller amount could I reach by removing one coin?
Store solutions you have already calculated instead of recalculating them.
Extra Test
coins = [1, 3, 4]
amount = 6
Think carefully before assuming the largest coin should always be used first.




Challenge 5: Merge Overlapping Intervals
Problem


Each pair represents a start and end value:
intervals = [
    [1, 3],
    [2, 6],
    [8, 10],
    [9, 12]
]
Write:
def merge_intervals(intervals):
    pass
Return:
[[1, 6], [8, 12]]
Vital Hints
Comparing intervals becomes easier if they are ordered by their starting point.
Keep one current interval.
Compare the next interval's start with the current interval's end.
Ask:
Do these intervals overlap?
If they do, extend the current interval.
If they do not, save the current interval and begin another.

Problem

def missing_number(numbers):
    pass
Examples
[3, 0, 1] → 2

Do not sort the list.

Problem

graph = {
    "A": ["B", "C"],
    "B": ["D"],
    "C": ["D", "E"],
    "D": ["F"],
    "E": ["F"],
    "F": []
}
Write:
def shortest_path(graph, start, target):
    pass
Return the shortest path from start to target.
Example
start = "A"
target = "F"
Possible output:
["A", "B", "D", "F"]
Vital Hints
You want the path with the fewest edges.
Which graph traversal explores nodes level by level?
A queue is useful here.

You may also need to keep the path used to reach that node.
Keep track of visited nodes to avoid loops.

Challenge 9: Validate a Binary Search Tree
Problem
Write:
def is_valid_bst(root):
    pass
Return True if the tree is a valid Binary Search Tree.
A valid BST must follow:
all values on the left < node value
all values on the right > node value
Example
       8
       / \
      3   10
     / \    \
    1   6    14
Output:
True
But:
       8
       / \
      3   10
         /
        4
should return:
False
Vital Hints
Checking only a node against its direct children is not enough.
A value deep inside the right subtree must still be greater than the root.
Think about passing down a valid:
minimum value
maximum value
for each node.

Challenge 10: Detect a Cycle in a Graph
Problem
Write:
def has_cycle(graph):
    pass
The graph is represented using an adjacency list.
Example:
graph = {
    "A": ["B"],
    "B": ["C"],
    "C": ["A"]
}
Return:
True
because:
A → B → C → A
forms a cycle.
Vital Hints
Simply knowing whether a node was visited before is not always enough.
During traversal, distinguish between:
nodes visited sometime in the past
and:
nodes currently being explored
If you reach a node that is already in the current exploration path, you have discovered a cycle.
Think about how recursion and a set could help.
Further Hint:
https://www.w3schools.com/python/python_dsa_graphs.asp
